Chamber Website - Link https://brunastockett7.github.io/chamber/

This is a multi-page Chamber of Commerce website built with HTML, CSS, and JavaScript.

I created this project to practice building a complete, responsive website with multiple pages, shared styles, dynamic content, and user interaction.

What this site includes

Multiple pages (Home, Discover, Directory, Join, Marketplace)

Responsive layout using CSS

JavaScript for dynamic features

Organized folders for data, images, styles, and scripts

Deployed using GitHub Pages

Tech used

HTML

CSS

JavaScript

Project structure
chamber/
├── css/           # Stylesheets
├── data/          # JSON and data files
├── images/        # Images and assets
├── js/            # JavaScript files
├── index.html     # Home page
├── discover.html
├── directory.html
├── join.html
├── marketplace.html
└── thankyou.html

How to view the site

You can open the HTML files locally or view the live site via GitHub Pages.

Why I built this

This project helped me understand how to structure a larger front-end project, reuse styles and scripts across pages, and add interactivity with JavaScript.

It was also great practice for building something that feels like a real website, not just a single page.
